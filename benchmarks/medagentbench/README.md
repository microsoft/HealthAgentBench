# MedAgentBench Benchmark Assets

This directory stores MedAgentBench runtime assets and local infrastructure config.

- `assets/tasks.json`: source tasks used by `scripts/medagentbench/import_tasks.py`
- `docker-compose.yaml`: dockerized runtime scaffold for a local FHIR endpoint

Use scripts in `scripts/medagentbench/` for setup, startup, and import.
