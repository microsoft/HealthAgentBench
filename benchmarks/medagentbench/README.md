# MedAgentBench Benchmark Assets and Runtime

This directory stores MedAgentBench runtime config and benchmark-specific adapters.

- canonical source assets are in `data/medagentbench/`:
  - `test_data_v2.json`
  - `funcs_v1.json`
  - `SHA256SUMS` (generated by `scripts/medagentbench/setup.sh`)
- `docker-compose.yaml`: Docker Compose runtime definition for a local HAPI FHIR server

## Workflow

```bash
# 1) Prepare benchmark assets
bash scripts/medagentbench/setup.sh

# 2) Start local FHIR runtime
bash scripts/medagentbench/fhir_up.sh

# 3) Verify FHIR readiness
curl -sSf http://localhost:8080/fhir/metadata | head -c 200

# 4) Import and group tasks by repo task type
python scripts/medagentbench/import_tasks.py \
  --input data/medagentbench/test_data_v2.json \
  --funcs-json data/medagentbench/funcs_v1.json \
  --output-root tasks \
  --split std

# 5) Run a small benchmark slice
python experiments/run.py \
  --task medagentbench \
  --split std \
  --max-tasks 3 \
  --backend azure_openai \
  --model gpt-5.2 \
  --api-version 2025-03-01-preview \
  --fhir-base-url http://localhost:8080/fhir

# 6) Evaluate run outputs
python benchmarks/evaluate.py \
  --task medagentbench \
  --results experiments/results/medagentbench/<run-id>/results.jsonl

# 7) Stop runtime
bash scripts/medagentbench/fhir_down.sh
```

## Demo Run

Assuming the FHIR runtime is already running:

```bash
uv run python experiments/demo.py \
  --backend azure_openai \
  --model gpt-5.2 \
  --api-version 2025-03-01-preview \
  --fhir-base-url http://localhost:8080/fhir
```

Type prompts in the terminal. Exit with `quit`, `exit`, or EOF (`Ctrl-D`).
