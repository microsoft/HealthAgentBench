# MedAgentBench Benchmark Assets and Runtime

This directory stores MedAgentBench runtime assets and local infrastructure config.

- `assets/tasks.json`: source tasks used by `scripts/medagentbench/import_tasks.py`
- `assets/SHA256SUMS`: checksums generated by `scripts/medagentbench/setup.sh`
- `docker-compose.yaml`: Docker Compose runtime definition for a local FHIR endpoint
- `runtime/`: container runtime files for the local FHIR-compatible mock service

## Quickstart

```bash
bash scripts/medagentbench/setup.sh
bash scripts/medagentbench/fhir_up.sh
curl -sSf http://localhost:8080/metadata | head -c 200
bash scripts/medagentbench/fhir_down.sh
```

Use scripts in `scripts/medagentbench/` for setup, startup, shutdown, and task import.
