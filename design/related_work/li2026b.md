# HEARTS: Benchmarking LLM Reasoning on Health Time Series

**ID:** `li2026b` | **Year:** 2026 | **URL:** https://arxiv.org/abs/2603.06638

## Summary

HEARTS (Health Reasoning over Time Series) is the first unified benchmark for evaluating hierarchical reasoning capabilities of LLMs over diverse health time series. It integrates 16 real-world datasets across 12 health domains and 20 signal modalities, with 110 tasks grouped into four capability families: Perception, Inference, Generation, and Deduction. Evaluation of 14 state-of-the-art LLMs on 20K+ test samples reveals that current models substantially lag behind specialized ML models and rely heavily on low-complexity heuristics rather than genuine temporal reasoning.

## Key Contributions

- First diverse health-focused time series reasoning benchmark spanning 12 domains, 20 signal modalities, and 110 tasks.
- Hierarchical task taxonomy (Perception, Inference, Generation, Deduction) that goes beyond standard multiple-choice, requiring exact numerical answers and open-ended generation.
- Comprehensive evaluation of 14 frontier LLMs revealing consistent gaps in health time series reasoning.
- Designed as a living, community-driven ecosystem with standardized contribution protocols for new datasets, tasks, and agent architectures.

## Methodology

- **Datasets:** 16 real-world datasets covering motion (Capture24, PAMAP2), metabolic (Shanghai Diabetes, CGMacros), surgery (VitalDB), sleep (SHHS), respiration (Harespod), emotion (PhyMER), ophthalmology (PERG-IOBA), eye movement (GazeBase), behavior (GLOBEM), speech (Bridge2AI-voice, VCTK), gesture (GrabMyo), and COVID cough (CoughVID, Coswara).
- **Signal diversity:** Input lengths range from 60 to over 1M steps; sampling frequencies span from daily metrics to 48kHz.
- **Evaluation framework:** Uses the CodeAct framework — time series data are stored as files (.npy, .csv), and the LLM writes Python code to load and analyze the data programmatically. This sidesteps context window limits for long sequences.
- **Input format ablation:** Also tests direct text input and visual (image) input on short-sequence tasks. File access and text achieve near-parity; visual input degrades performance notably.
- **Models:** 14 LLMs evaluated: GPT-4.1 Mini, GPT-5 Mini, Claude 4.5 Haiku, Gemini 2.5 Pro/Flash, Qwen3 235B, Qwen3 Coder 480B, DeepSeek V3.1, Llama 4 Maverick, Grok 4.1 Fast, MiniMax M2, GLM 4.7, Nemotron Nano 12B V2, Kimi K2 Thinking.
- **Metrics:** Accuracy, IoU, or sMAPE depending on task type; naive baselines included for contextualization.

## Results

- **Finding 1:** LLMs substantially underperform specialized ML models. Performance on HEARTS is only weakly correlated with general reasoning scores (Intelligence Index).
- **Finding 2:** LLMs rely heavily on low-complexity heuristics (copy-paste with noise injection, linear interpolation, polynomial fitting, basic statistical averaging) rather than genuine temporal reasoning. Generation tasks are particularly formulaic.
- **Finding 3:** Performance degrades with increasing temporal complexity — longer input sequences and higher sampling frequencies correlate with worse performance. A shared, model-agnostic difficulty ordering exists across domains and modalities.
- **Finding 4:** Models within the same architectural family (GPT, Qwen, Gemini) show highly consistent behavioral patterns, while scaling does not necessarily improve proficiency.
- **Finding 5:** Input format mainly shifts absolute performance; relative task difficulty remains consistent across file, text, and image formats.
- **Additional:** Domain-specialist agents (e.g., Biomni) do not outperform generalist CodeAct agents, due to toolset sparsity for time series analysis. Adding auxiliary signals often fails to improve or even degrades performance.
- **Top models:** GLM 4.7 (0.66), Grok 4.1 Fast and Kimi K2 Thinking (0.65), DeepSeek V3.1 (0.64).

## How LLMs Encode Time Series Data

The primary input method is the **CodeAct framework**: time series are stored as files (.npy arrays, .csv), and the LLM is prompted to write Python code that reads and analyzes the data from these files. The model never needs to ingest the full raw numerical sequence in its prompt, which is critical given input lengths up to 1M+ steps.

On short-sequence tasks (L < 1000), three input formats were compared:
- **File access (CodeAct):** Best or tied for best performance.
- **Direct text:** Raw numerical values in the prompt; near-parity with file access.
- **Visual (image):** Time series plotted as images; notable performance degradation.

An important observation from the modality analysis: current LLM tokenization strategies are fundamentally misaligned with continuous, high-frequency biosignals (e.g., ECG, CGM), creating a "representation gap" that scaling alone cannot bridge. Higher-level structured signals (HR, aggregated daily data, blood pressure) are more tractable.

## Relevance to My Work

- Highly relevant benchmark for understanding the capabilities and limitations of LLM agents in healthcare time series tasks.
- The CodeAct-based agentic evaluation paradigm (LLMs writing code to process data) is directly relevant to EHR agent design — agents may similarly need to programmatically interact with clinical data rather than ingesting it as raw text.
- The finding that domain-specialist agents (Biomni) fail to outperform generalists due to toolset sparsity highlights the importance of modality-specific computational tools in agent design.
- The "representation gap" for continuous physiological signals is an important consideration when designing agents that interface with clinical monitoring data.

## Raw Notes

- Benchmark is positioned as a "living ecosystem" — extensible via standardized APIs for new tasks and agents.
- Task design follows three principles: evidence-grounded significance, context-grounded label validity, and data-grounded multi-step reasoning (formalized as MDP trajectories).
- Perception tasks benefit greatly from step-by-step instructions (mean 0.90) vs. result-oriented prompts (mean 0.59), indicating LLMs lack autonomous reasoning for signal processing.
- Code and data available: https://github.com/yang-ai-lab/HEARTS and https://huggingface.co/datasets/yang-ai-lab/HEARTS

## Related Work

### SleepFM: A Multimodal Sleep Foundation Model for Disease Prediction

- **Authors:** Thapa, Kjaer, He, Covert, Moore, Hanif, Ganjoo, Westover, Jennum, Brink-Kjaer, Mignot, Zou
- **Year:** 2026
- **URL:** https://www.nature.com/articles/s41591-025-04133-4

SleepFM is a multimodal sleep foundation model trained on 585,000+ hours of PSG recordings from ~65,000 participants across multiple cohorts (Stanford Sleep Clinic, BioSerenity, MESA, MrOS). It uses a channel-agnostic architecture with a novel leave-one-out contrastive learning (LOO-CL) approach to align representations across modalities (EEG, ECG, EMG, respiratory) while remaining resilient to missing or heterogeneous channels. From a single night of sleep, SleepFM predicts 130 conditions with C-Index ≥ 0.75, including all-cause mortality (0.84), dementia (0.85), heart failure (0.80), and stroke (0.78). It also performs competitively on standard sleep analysis tasks (sleep staging F1 0.70–0.78, apnea detection accuracy 0.87).

**Relevance to HEARTS:** SleepFM's released datasets and pretrained models are directly usable for HEARTS benchmark tasks in the sleep domain. Specifically:
- **Datasets:** SHHS (used in both HEARTS and SleepFM), MESA, and MrOS are publicly available at https://sleepdata.org. Stanford sleep data released at https://bdsp.io/content/hsp/2.0/. These overlap with or complement the HEARTS sleep tasks (sleep staging, arousal detection, ECG-based predictions).
- **Pretrained model:** SleepFM's embeddings could serve as specialized feature extractors for HEARTS sleep/physiological tasks, potentially closing the gap between LLM agents and specialized ML models that HEARTS identifies. Code available at https://github.com/zou-group/sleepfm-clinical.
- **Key contrast:** HEARTS shows LLMs struggle with physiological time series reasoning (e.g., sleep staging accuracy 0.41 avg across LLMs vs. 0.81 SOTA). SleepFM achieves SOTA-level performance through domain-specific pretraining — exactly the kind of specialized model that consistently outperforms LLM agents in the HEARTS evaluation.
