# n2c2 2018 Track 1: Cohort Selection (JAMIA 2019)

- Paper: https://doi.org/10.1093/jamia/ocz163
- Data: https://portal.dbmi.hms.harvard.edu/projects/n2c2-nlp/
- HuggingFace: https://huggingface.co/datasets/bigbio/n2c2_2018_track1
- Title: *Cohort Selection for Clinical Trials: n2c2 2018 Shared Task Track 1*
- Organizers: Amber Stubbs, Michele Filannino, Ergin Soysal, Samuel Henry, Ozlem Uzuner
- Source read date: March 3, 2026

## Summary
The n2c2 2018 Track 1 shared task addresses automated cohort selection for clinical trials using NLP over longitudinal patient medical records. Systems must determine, for each patient, whether they meet or do not meet each of 13 predefined selection criteria drawn from real clinical trial eligibility requirements. These criteria span a range of NLP difficulties: straightforward measurement detection (HbA1c values), clinical inference (aspirin use specifically for MI prevention), temporal reasoning (ketoacidosis within the past year), and expert-level clinical judgment (major diabetes-related complications).

The dataset consists of 288 patients (202 train, 86 test) with longitudinal clinical narratives from the 2014 i2b2/UTHealth shared task. Each patient record is annotated with binary labels ("met"/"not met") for all 13 criteria. Inter-annotator agreement averaged 84.9%. Evaluation uses micro-averaged F1 score.

Top-performing systems achieved micro-averaged F1 above 0.90. Hybrid systems combining hand-crafted rules with machine learning tended to perform best, as different criteria required fundamentally different reasoning capabilities.

## Main Contributions
1. Established a benchmark for automated clinical trial cohort selection from unstructured longitudinal EHR narratives against 13 real-world criteria.
2. Demonstrated the multi-faceted nature of cohort selection NLP — requiring entity recognition, measurement extraction, temporal reasoning, negation handling, and clinical inference.
3. Provided a reusable annotated dataset of 288 longitudinal patient records with document-level eligibility labels.
4. Showed that hybrid approaches (rules + ML) were competitive with or superior to purely learned approaches.

## Method and Setup (High Level)
- 13 parallel binary text classification problems at the patient level.
- Input: longitudinal clinical record (one or more clinical notes).
- Output: for each of 13 criteria, a binary label (met/not met).
- Criteria: DRUG-ABUSE, ALCOHOL-ABUSE, ENGLISH, MAKES-DECISIONS, ABDOMINAL, MAJOR-DIABETES, ADVANCED-CAD, MI-6MOS, KETO-1YR, DIETSUPP-2MOS, ASP-FOR-MI, HBA1C, CREATININE.
- Evaluation: micro-averaged precision, recall, F1 across all criteria and patients.

## Key Findings
- Top systems ~0.90-0.91 micro-averaged F1, with considerable variation across individual criteria.
- Criteria requiring straightforward value extraction (HBA1C, CREATININE) were easier; those requiring inference or temporal reasoning (ASP-FOR-MI, KETO-1YR) were harder.
- Deep learning approaches (early BERT-based) showed promise but did not uniformly outperform well-designed rule-based systems.
- Ensemble and multi-strategy approaches that selected different methods per criterion outperformed single-model approaches.

## Limitations Noted by Authors
- Small dataset (288 patients) by modern standards.
- Document-level labels only — no span-level evidence annotations in the standard release.
- Single source institution.
- Fixed set of 13 criteria — generalization to novel criteria not evaluated.
- Significant class imbalance for several criteria.

## Relevance to EHR Co-Scientist

### Alignment
- Directly tests cohort construction and phenotyping from clinical text.
- Multi-skill reasoning (measurement extraction, temporal reasoning, clinical inference) mirrors agentic tool orchestration.
- Each criterion effectively defines a clinical phenotype.

### Differences
- Uses unstructured text only (no structured EHR tables).
- Small dataset; modern LLMs may saturate it quickly.
- External data source (not MIMIC), requires separate DUA.

### Implications for This Repository
1. Can benchmark cohort selection from clinical narratives as a component task.
2. The finding that different criteria need different strategies supports the multi-tool agentic approach.
3. The small size and text-only focus mean this should be supplemented with structured-data cohort benchmarks.
