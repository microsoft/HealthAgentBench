# Design

This folder contains project design docs, brainstorm notes, planning materials, and related-work notes for MedCLI.

For local workflow and benchmark-intake guidance in this directory, see [AGENTS.md](AGENTS.md).

In particular, benchmark additions should start in `design/related_work/` and `design/tasks.md` before implementation work begins elsewhere in the repo.

## Documents

| [scope.md](scope.md) | MVP scope definition, phased roadmap, and brain dump |
| [tasks.md](tasks.md) | Candidate agentic EHR tasks and benchmarking ideas |
| [tools.md](tools.md) | Tool suite design — categories, specifications, and interfaces |
| [architecture.md](architecture.md) | High-level system architecture and design decisions |
| [ideas/](ideas/) | Freeform brainstorm notes and rough drafts |
