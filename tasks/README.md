# Tasks

This directory contains generated Harbor task environments for benchmark integrations.

Current benchmark tasks in this repo:

| Benchmark | Task Directory | Description | Notes |
|-----------|----------------|-------------|-------|
| **MedAgentBench** | `medagentbench/` | Interactive EHR benchmark focused on multi-step retrieval, reasoning, and structured action tasks over clinical data. | Harbor-generated benchmark task built from raw benchmark assets under `scripts/medagentbench/`. |
| **EHRSQL_Lite** | `ehrsql/` | Text-to-SQL benchmark over EHR databases (MIMIC-III, eICU). We use a lite version that covers 250 samples from MIMIC-III and 250 samples from eicu. Agent generates SQL queries or identifies unanswerable questions. |THE harbor task directories are generated using `scripts/ehrsql/generate_harbor_tasks.py`.|
| **MIMIC-IV MEDS Extraction ETL** | `mimic_iv_meds/` | ETL benchmark for converting the open MIMIC-IV demo dataset into MEDS by following the pinned upstream `MIMIC_IV_MEDS` repo. | Adapted Harbor task with staged demo input, agent-run `uv` setup, and directory-output verification against a gold summary. |
| **MIMIC-CXR Report Generation** | `mimic_report_gen/` | Patient-aware multimodal radiology-report generation on MIMIC-CXR v2.1.0. One task per patient: the agent sees prior studies (images + reports + timestamps) and drafts FINDINGS and IMPRESSION for a single target study. | Task tree is generated by `scripts/mimic_report_gen/generate_harbor_tasks.py` from the credentialed PhysioNet release. Per-trial BLEU / ROUGE-L plus pooled CheXbert F1-14 via a `uv-script` aggregator. |
| **MIMIC-IV-DQ** | `mimic_iv_dq/` | Synthetic data-quality detection over a corrupted MIMIC-IV-demo subset. Four tasks (one per error family + a combined task) inject impossible values, conflicting/duplicate records, and demographic contradictions; the agent flags suspicious rows. Cluster-level recall + row-level precision combined into F1. | Task tree generated by `scripts/mimic_iv_dq/generate_harbor_tasks.py`. Demo CSVs downloaded at Docker build time. Anti-cheat is source-name obfuscation only (no `/etc/hosts` egress block — it's read-only at image build). |
| **Clinical Trial Matching** | `clinical_trial_matching/` | Patient-to-clinical-trial retrieval (built from TREC Clinical Trials 2021). Each of 10 tasks hands the agent one synthetic admission note plus the topic's judged-pool corpus of clinical-trial XMLs and asks for a ranked NCT-ID list; scored by NDCG@10 against physician-judged graded qrels (eligible / excluded / non-relevant). | Task tree generated by `scripts/clinical_trial_matching/generate_harbor_tasks.py`. Per-topic corpus is fetched on demand from the upstream zip snapshot via HTTP range requests, cached host-side at `scripts/clinical_trial_matching/assets/raw_cache/` (gitignored), bind-mounted into each container with a per-topic `flock`. NDCG@10 via `pytrec_eval`. |

For the canonical repo-level workflow for integrating a new benchmark, see `design/benchmark_addition_workflow.md`.

For benchmark-specific task generation details, see `scripts/<benchmark>/README.md`.
